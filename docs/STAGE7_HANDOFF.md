## 1. Инструкция по быстрому запуску системы

### Автономный запуск (Рекомендуемый для защиты, без внешних зависимостей)

#### Шаг 1. Проверка окружения (диагностика зависимостей и портов)
```powershell
python scripts/verify_environment.py
```
*(Должен вернуть статус `OVERALL VERIFICATION STATUS: [PASS]`)*

#### Шаг 2. Запуск Backend API (FastAPI, порт 8050)
```powershell
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8050
```
- Swagger OpenAPI документация: `http://127.0.0.1:8050/docs`
- Проверка работоспособности: `http://127.0.0.1:8050/api/health`

#### Шаг 3. Запуск Frontend интерфейса (React + Vite, порт 5180)
```powershell
cd frontend
npm run dev -- --port 5180
```
- Откройте в браузере: `http://localhost:5180`
- Поддерживаемые разрешения экрана: **1440×900** (основное) и **1280×800**.
