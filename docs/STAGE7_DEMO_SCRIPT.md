# СЦЕНАРИЙ ЖИВОЙ ДЕМОНСТРАЦИИ НА ЗАЩИТЕ ДИПЛОМА (5–7 МИНУТ)

- **Продукт:** Интеллектуальная система BuildingPulse AI (`v0.7.1-stage7.1`)
- **Тема диплома:** «Разработка интеллектуальной системы анализа данных инженерных систем зданий».
- **Целевая аудитория:** Государственная экзаменационная комиссия (ГЭК), рецензент, научный руководитель.
- **Подготовка перед выходом к трибуне:**
  1. В терминале запущен бэкенд: `python -m uvicorn backend.app.main:app --port 8050`
  2. В браузере открыт фронтенд: `http://localhost:5180` в полноэкранном режиме (1440×900 или 1280×800).
  3. Проверено: интернет не требуется, все работает автономно на SQLite + Parquet.
