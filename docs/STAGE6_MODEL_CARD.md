## 2. Пространство признаков и защита от утечек

### Входные признаки адаптированных моделей:
1. `OA_TEMP` — температура наружного воздуха (°C);
2. `RA_TEMP` — температура рециркуляционного воздуха из зон (°C);
3. `SA_TEMPSPT` — динамическая уставка температуры притока от контроллера (°C);
4. `CHWC_VLV_DM` — команда привода клапана охлаждения (доля 0..1);
5. `OA_DMPR_DM` — команда привода заслонки наружного воздуха (доля 0..1);
6. `RA_DMPR_DM` — команда привода заслонки рециркуляции (доля 0..1);
7. `MA_TEMP_EST` — физическая оценка температуры смеси по тепловому балансу:
   $$\hat{T}_{ma} = \alpha T_{oa} + (1-\alpha) T_{ra}, \quad \alpha = \text{clip}(OA\_DMPR\_DM, 0.10, 1.0)$$

### Категорически исключенные признаки:
- `SA_TEMP` — целевая переменная (строго запрещена на входе инференса, исключены лаги и скользящие статистики цели);
- `AHU9ahuMaTemp` — сырой тег BMS (доказано идентичен `SA_TEMP`, исключен для предотвращения авторегрессионного коллапса);
- Метки дефектов (`source_fault_label`, `is_fault_raw`).

## 4. Ограничения и допустимая область применения

1. **Эксплуатационный фильтр:** Модели применяются только при работающем приточном вентиляторе (`SF_SPD_DM >= 0.5`). При выключенном вентиляторе возвращается статус `AHU_OFF`.
2. **Сезонность:** Выборка охватывает весенне-летний период южного полушария (октябрь–ноябрь 2013). Поведение в глубоком зимнем режиме отопления (при минусовых температурах наружного воздуха) не исследовано.
3. **Локализация неисправностей:** Модели являются **виртуальными датчиками теплового баланса**, а не автоматическими классификаторами причин. Превышение порога фиксирует аномалию контура, но не доказывает конкретный тип поломки.
