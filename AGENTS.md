# AGENTS.md — Правила и контекст для автономных агентов BuildingPulse AI

## 1. Официальная тема и цель проекта
- **Тема диплома:** «Разработка интеллектуальной системы анализа данных инженерных систем зданий».
- **Целевой продукт:** Интеллектуальная платформа диагностики данных вентиляционной установки AHU (Air Handling Unit), развиваемая в демонстрируемый веб-продукт.
- **Научный фокус:** Исследование качества локализации неисправностей при ограниченной наблюдаемости (Basic vs Extended наборы каналов) и механизм достаточности диагностических свидетельств.

## 2. Границы текущего этапа (Этап 1: Фундамент + Паспорт данных)
- **Делаем сейчас:**
  - Каркас приложения: FastAPI backend + React/TypeScript (strict) frontend + Tailwind CSS + Apache ECharts.
  - Хранение метаданных в БД (PostgreSQL / SQLite fallback для локального запуска без Docker), временных рядов — в Parquet.
  - Безопасный импорт и валидация CSV.
  - Отображение реальных временных рядов с downsampling (max_points).
  - Интерактивная SVG-схема AHU (OA, RA, MA, охлаждающий змеевик/клапан, вентилятор, SA) с синхронизацией по курсору.
  - Воспроизведение исторических данных (Play/Pause/Seek/Speed x1/x5/x20).
  - Панель качества данных (монотонность времени, пропуски, дубликаты, stuck-signal).
  - Минимальный детерминированный диагностический baseline. Метка ground truth хранится отдельно от предсказаний (`source_label` vs `detected_event`).
  - Первичный паспорт данных LBNL SD-AHU, сопоставление каналов (`DATA_DICTIONARY.md`), манифест (`DATASET_MANIFEST.md`), проект исследовательского протокола (`RESEARCH_PROTOCOL_DRAFT.md`).
  - Воспроизводимый Docker Compose, тесты, документация.
- **ЗАПРЕЩЕНО на этапе 1:**
  - Обучать LightGBM / строить ML-модели.
  - Строить полноценный Decision Layer, Conformal Prediction, Brick RDF/SPARQL, LLM-агента, 3D-двойник.
  - Выдавать синтетические данные за реальные или симуляции LBNL за реальное здание.
  - Выдумывать проценты уверенности или диагнозы без калиброванного классификатора.
  - Делать `git commit`, `git push`, `git merge`, deploy без явного разрешения владельца.

## 3. Стек технологий
- **Backend:** Python 3.11, FastAPI, Pydantic v2, SQLAlchemy 2, PyArrow, Pandas, Pytest, Uvicorn.
- **Frontend:** React 18 / 19, TypeScript (strict), Vite, Tailwind CSS, Apache ECharts.
- **Хранение данных:** Parquet (`data/processed/`), PostgreSQL (Docker Compose) / SQLite (локальный dev-режим).
- **Контейнеризация:** Docker Compose (сервисы `frontend`, `backend`, `db`).
