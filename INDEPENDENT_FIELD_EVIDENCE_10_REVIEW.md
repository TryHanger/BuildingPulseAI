## Замечания

1. `test_altered_evidence_is_withheld` проверяет главным образом SHA-замок фиксированного файла, **а не** отдельный семантический валидатор каждого искусственно испорченного timestamp. Для immutable reviewed bundle это допустимо; нельзя распространять вывод теста на произвольный будущий upload/API.

3. Отметка +5/+10 минут — **времена первых записанных OFF относительно расписания**; не реальный момент физического отключения.
4. Отсутствует официальный Git diff/status по исходному репозиторию: поставка от проверенного локального snapshot без Git-метаданных; не заявлять git parity как проверенный.
