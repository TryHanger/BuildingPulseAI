# API v1 · журнал изменений

## 1.0.0-rc.11 · 2026-11-08

G36-1wk reports the separate paired and unpaired gates and the run denominator. Two publisher oracle exceptions are marked in EXTRA_SIMULATED. G36-5wk and the fixed BASIC scorer retain their accepted behavior.

## 1.0.0-rc.10 · 2026-11-07

- G36 Investigator adds a separate unpaired G36-1wk window. Full-run denominator, SAT residual distribution and source exposure are visible. Existing G36-5wk remains the default.

## 1.0.0-rc.9 · 2026-11-07

- G36-5wk получает четыре сценария и отдельную сравнительную таблицу с охватом, счётчиками и распределением команды. Добавлены статус применимости и независимое обозначение механического enable как UNKNOWN.

## 1.0.0-rc.8 · 2026-11-07

- Добавлено отдельное read-only окно G36-5wk с модельными секундами, проверкой температурного симптома и явно отделённым симуляционным oracle.

## 1.0.0-rc.7 · 2026-11-07

- Investigation добавляет `confirmation_state`. Нарушение на границе окна отдельно отмечается как `PENDING` до поступления дополнительных отсчётов. Унаследованные статусы и правила подтверждения сохранены.

## 1.0.0-rc.6 · 2026-11-07

- Отчёт G4.1 отдельно возвращает число нарушающих отсчётов вне подтверждённых к концу окна эпизодов.

## 1.0.0-rc.5 · 2026-11-07

- Добавлен `GET /api/v1/investigation` с раздельными статусами обнаружения и причины, группировкой исходных свидетельств и экспортом JSON/HTML.
- `GET /api/v1/datasets?demo=true` явно выбирает изолированный источник `DEMO_FIXTURE`. Каталог по умолчанию и лента G3 содержат LBNL.
- `GET /api/v1/series` добавляет идентификатор, SHA-256 и происхождение результата. Существующие форматы времени, значений и пагинации сохранены.

## 1.0.0-rc.4 · 2026-11-07

- Добавлен read-only `GET /api/v1/incidents` с ограниченным окном, подтверждёнными по времени симптомами, охватом и доказательствами. Лента LBNL отделена от UI_MOCK_V0.
- Точечная диагностика добавляет `symptom_evaluation` для нижней температурной проверки. Причина остаётся не подтверждена, QA команды и оценка входов правила видны раздельно.
- Некорректные дробные измерения EXTRA отмечаются отдельным флагом качества.
- Существующий `GET /api/v1/modes` сохранён. Исходный план описывал equipment-scoped маршрут с `start/end` в UTC. Реализованный G2 запрашивает идентифицированный источник, `start` в исходном времени и `limit`, а состояние физического охлаждения передаёт как неизвестное.

## 1.0.0-rc.3 · 2026-11-07

- Добавлен read-only `GET /api/v1/modes` для сегментов вентилятора, погодного контекста и качества временной сетки.
- Точечная диагностика использует предысторию по версии политики, возвращает качество по каналам и отдельную применимость методов.
- Investigator показывает сегменты и переходы на исходной временной шкале. Независимые физические режимы имеют статус `UNKNOWN`.

## 1.0.0-rc.2 · 2026-11-07

- v1 возвращает статус `UNVERIFIED_UNIT` и предупреждение `SEMANTICS_UNVERIFIED` для raw давления и его уставки.
- Точечный результат сообщает `cause_status=NOT_ASSESSED`. Превышение диапазона команды классифицируется как `SIGNAL_RANGE_VIOLATION`. Проверка различает пропуск канала, останов вентилятора, невалидный статус и невалидное значение.
- Каталог содержит покрытие срезов. Investigator поддерживает прямой переход по исходному времени и рисует разрывы на шкале прошедших секунд.
- Годовой здоровый ряд читается из Parquet по временному индексу с проверкой обоих SHA. Кандидат режимной схемы проверяется отдельно.

## 1.0.0-rc.1 · 2026-11-07

Единственный контракт Investigator находится в [contracts/openapi-v1.yaml](contracts/openapi-v1.yaml). FastAPI отдаёт его через `GET /api/v1/openapi.json`. UI использует сгенерированные из него типы. `/openapi.json` относится к прежнему API FastAPI. Четыре публичные операции v1 доступны в коде и покрыты HTTP-проверками. Модели исторических fixtures помечены `x-historical-fixture-schemas`.

| Предложение F | Решение |
|---|---|
| Каталог датасетов и источников | Принято. `{items}` содержит идентификаторы датасета и установки, файл публикации, SHA-256, выпуск, лицензию, вид времени и состояние пары. Список ограничен 15 зарегистрированными срезами. |
| Реестр сигналов | Принято с `panel=BASIC|EXTRA`. EXTRA включает BASIC и каналы `EXTRA_SIMULATED`. `CHWC_VLV` — положение модели. `SYS_CTL` и oracle исключены из runtime. BASIC_PLUS_* сохранены внутри UI_MOCK_V0. |
| Ряды и разрывы | Приняты выровненные исходные отсчёты и повторяемый параметр `signal_ids`. Окна до 1440 точек с `next_start`, без Min-Max в v1. Разрыв определяется по 60-секундному шагу LBNL и сохраняется на границе страниц. null представляет пропуск значения. |
| Время ISO 8601 UTC и порог 30 минут | Заменены шкалой `SOURCE_SIMULATION_TIME` без смещения и шагом конкретного источника. Привязка к UTC и DST отсутствует. |
| Сегменты режимов и ожидаемый коридор | Сегментация и коридор отложены. На выбранном отсчёте сервер возвращает `OFF` при зафиксированном статусе вентилятора 0, иначе `UNKNOWN`. Показание вентилятора передаётся отдельно. |
| Evidence Inspector | Приняты отдельные статусы детекции, причины, качества, модели и применимости каждого метода. У возвращённых наблюдений есть версия метода, SHA и ID исходного свидетельства. Отсутствие роли возвращается в теле успешного ответа и сохраняет другие результаты. |
| Анализы, инциденты, отчёты и рекомендации | Отложены до валидации режима, порогов, агрегации и источников. Runtime возвращает точечную диагностику, страницы инцидентов работают как `DEMO_FIXTURE`. |
| Matched pairs | Отложены до проверки конфигурации и сопоставимости. `PAIR_NOT_VERIFIED` доступен в каталоге, реальный overlay заблокирован. |
| Ошибки и provenance | Ошибка HTTP видна в UI. Изменённый SHA источника даёт 409, отсутствующий CSV даёт 404, неверный параметр даёт 422. `VERIFIED_RUNTIME`, `DEMO_FIXTURE` и `LEGACY_ANALYSIS` отображаются раздельно. |

Согласование требований выполнено по одному исходному дереву. После приёмки изменения формата или семантики требуют новой записи здесь, пересборки типов и повторной проверки FastAPI и UI.
