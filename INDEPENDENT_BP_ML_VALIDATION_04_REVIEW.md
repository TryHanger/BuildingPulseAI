## Научные ограничения и замечания

- Прямой перенос **этого конкретного замороженного booster** невозможен на проверенные G36/CSIRO/RBC без обязательных сигналов или без изменения их семантики. `BLOCKED_EXTERNAL_VALIDATION` относится только к проверенному набору источников, не ко всем существующим datasets или всем возможным LightGBM.
- Native SAT использует **16 физических входов плюс 3 календарных**, а `SA_TEMP` — отдельная наблюдаемая цель; весь BASIC содержит 17 физических величин. В G36-1wk нет двух сигналов return fan, временной origin для календаря не аттестован, и контрольная последовательность отличается; не заполнять отсутствующие каналы нулями и не выдавать surrogate за прямой cross-domain перенос.
- Полный замороженный benchmark с Ridge/PCA на той же минутной маске **не может быть восстановлен из доступных неизменяемых артефактов**. Допускается разработать **новый** честный bench с новым идентификатором и явным переобучением всех сравнителей на заранее фиксированных данных — не переписывая REPRO-01.
- `363 passed` и HTTP/Playwright получены из журнала агента. Повторение скрипта арифметики не заменяет переобучение, исходный native inference на внешнем источнике или full-stack runtime validation.
- Внешний блокирующий статус должен оставаться видимым в UI/API. Никакой автоматической эскалации `MODEL_ANOMALY` в `FDD confirmed`, равно как `field ready`.
