# Проверки BP-ML-REPRO-01

- Полный официальный архив, SHA/CRC и метаданные всех 21 CSV сверены. 12 прошли структурный допуск. Архив, TTL и издательские документы идентифицированы SOURCE_SHA256SUMS.txt.
- 326 pytest, из них 6 специфических проверок: BRICK и fallback, роли, отсутствие self-target/labels/EXTRA в BASIC, режим и разрывы, хронология, абсолютные остатки, mean/max, нулевая SD, строгий порог, дубликаты. Дополнительный offline CLI negative test снял SAT и получил NOT_EVALUABLE без fit. В действующем приложении нового API нет.
- По экспортированным daily scores независимо пересчитаны 1 320 сезонных/полных строк AUC и confusion. Проверен max по целям. Метрики обозначены по своей семантике, AUC отдельно от precision/recall/FPR.
- Строгая сборка TypeScript, OpenAPI, 8 fixture types, сверка сгенерированного TS, HTTP smoke и Playwright G0/G3/G4/G36 прошли. Сборка сохраняет прежнее предупреждение размера бандла. Docker и Compose — NOT_RUN. Новых исследовательских страниц или API нет, поэтому UI missing-channel E2E — NOT_APPLICABLE.
- Источник обработан примерно за 61 с с пиком 1 316 964 KiB. Основные прогоны по порядку PAPER, STRICT, BASIC и BASIC без команд заняли 121,86 / 35,86 / 26,31 / 29,02 с. Peak RSS 1 329 008 / 1 239 836 / 1 089 764 / 1 064 620 KiB. Фактическая среда и журналы GNU time приложены.
- Прогоны seed 0–9 завершились. Повторы PAPER seed 0 и BASIC seed 42 дали побайтно те же metrics.csv, coverage.csv и run.json. В PAPER менялись только отдельные медианы/разрыв рангов (до 1,8×10⁻¹⁵) и два значения в validation-errors.csv (до 5,6×10⁻¹⁷). В BASIC максимальное расхождение daily z составило 0,00013433 на 13 из 3 540 строк, порядок рангов и пороговые решения совпали. Побайтовая воспроизводимость промежуточных scores не подтверждена. Детали в evidence/replay-comparison.log.
- SHA-256 для исходных и изолированных raw/processed/SQLite совпали до и после работы. Проверены контрольные суммы протокола и скриптов, зафиксированные до fit.
