# Утечки, режим и абляция

- Цель исключена из своих признаков. Из Datetime используются только текущие hour/month/day_of_week. Нет severity, labels, будущих значений, oracle или стандартизации на fault. Нормировка Ridge/PCA обучается только на здоровой train. Residual calibration использует только здоровую calibration. Состав признаков выведен из TTL и ограничивается реестром панели.
- В PAPER healthy validation одновременно задаёт mean/SD остатка и даёт negative days. Оценка FPR потенциально оптимистична. На границе 2018-10-18 12:15 в healthy 527, в SA+2 586 оставшихся минут. Это один частичный день из 61 оценённого дня. По опубликованному recall предположительно использовалось 60 дней. Удаление одного дня при 49 TP не способно получить 50/60. Другие неизвестные — правило края дня, авторская версия библиотеки и противоречия Figure 15. Основной расчёт не менялся.
- STRICT и BASIC используют раздельные whole-day train/calibration/test с 2018-08-08 и 2018-10-20. Ни test healthy, ни fault не участвуют в калибровке. Тот же RUNNING gate для STRICT и двух BASIC arms исключает SYS_CTL и применяет 300 s задержку на нативном фан-статусе. Эквивалентность G2 проверена на разрывах. Физический fan run-proof и cooling_enable не установлены. В STRICT и BASIC на healthy покрыто 53 954/105 120 минут и 59/73 календарных дней. PAPER покрывает 55 737/107 265 минут и 61/75 дней. Летний и весенний test отсутствуют. Сравнение PAPER и STRICT одновременно меняет mask, context и split.
- FULL использует модельные положения приводов. BASIC исключает их, модельные скорости, расходы/мощность, давления с непроверенными единицами и SYS_CTL. Оба BASIC arms используют одинаковую маску и даты, в каждом 8 целей с минимум тремя BRICK-соседями до временных контекстов. При отсутствующем SAT отдельный прогон квалификатора возвращает NOT_EVALUABLE. Это end-to-end offline CLI, поскольку сервис не интегрирован.
- SA+2 °C, LightGBM BASIC с командами даёт AUC 0,9520 и 37/59 положительных дней при z>3. Без команд AUC 0,8725 и 27/59. У Ridge AUC 0,9908→0,7639, recall 23/59→0/59. У PCR AUC 0,8075→0,6662, recall 12/59→0/59. Команды — эндогенные следствия регулятора. Абляция не оценивает физический эффект команды.
- SAT setpoint comparator сохраняет одинаковый результат при удалении команд. Для SA+2 в STRICT/BASIC AUC 0,7182. При frozen z3 в BASIC нет тревог в 59 здоровых оценённых днях у LightGBM/Ridge/PCR. Это наблюдение на одной симуляции с зависимыми днями. Порог scalar PCA и SAT — локальное расширение, отсутствующее в таблицах статьи.
