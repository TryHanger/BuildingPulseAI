# BuildingPulse G4 · результат приёмки

**Дата** 7 ноября 2026, Asia/Qyzylorda.  
**Продуктовый gate** PASS в проверенной области.  
**Научный gate** BLOCKED_BY_DATA. Для fault-targeted метода нужен отдельный выбор и независимая оценка.

## Продуктовый цикл

- `DEMO_FIXTURE` проходит каталог → применимость → симптом → подтверждение по времени → исходные ряды → причины неприменимости и возможные объяснения → журнал → HTML и JSON. Один синтетический CSV служит источником для API, графиков и evidence. Подтверждение наступает в `2018-01-02T11:15:00` по шкале источника. Пять входных каналов дают 55 значений за 11 минутных наблюдений и один зависимый вычисленный факт.
- `SIMULATED_BENCHMARK` показывает ноль подтверждённых эпизодов и охват 187 192 из 525 540 строк за год (35,62%). Остальные 338 348 строк не оценены. На всех 15 сверенных источниках суммарно 333 209 из 797 700 строк и ноль нарушений FC2. Охват относится к измеренному симптому. Он не даёт оценку числа неисправностей.
- Источник, отпечаток правила и офлайновый индекс фиксируются SHA-256. Идентификатор эпизода сохраняется при seek. До временного подтверждения доступна явно обозначенная ретроспектива из выбранного эпизода. В пропуске данные и причина воздержания видны отдельно.
- Версия OpenAPI rc.5 дополняет маршруты rc.4. Журнал выбран как детерминированный серверный след. Фиксация пользовательских заметок и хранение отчётов в SQLite в этот workflow не входят.

## Проверки

| Gate | Результат |
|---|---|
| Python backend, контракт и исследования | 280 pytest PASS. Журнал `evidence/pytest.log`. |

Остаются наследованные предупреждения о размере frontend-бандла и версиях legacy-моделей. Compose smoke проверяет запуск стека и read-only workflow. Натурные испытания и диагностика причин имеют статус NOT_TESTED. Git metadata в исходных архивах отсутствуют, поэтому цепочка проверки основана на SHA архивов и файлов overlay.
