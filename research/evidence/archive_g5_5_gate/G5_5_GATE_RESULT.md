# BuildingPulse AI · G5.5

## Научный входной gate

**STOP_METHOD_NOT_EVALUABLE.** Оба проверенных кандидата остановлены до экспериментального протокола. На frozen BASIC статус **AMBIGUOUS_BY_OBSERVABILITY**. Набор позволяет обнаруживать симптом отклонения SAT, при этом несколько физических механизмов и смещение самого SAT могут давать одинаковые показания и команды. Формальный критерий допуска, условия режима и отрицательные контроли записаны в `PRE_EXPERIMENT_ENTRY_G5_5.md`. Заключение передаётся владельцу и независимому аудитору.

- В RBC-Nesbitt AHU2 найден Between-coil #62. Отдельные значения и заголовок подтверждены на номинале. Место относительно змеевика и связь с отдельным физическим термометром требуют подтверждения.
- Измеренный расход именно на ветви охлаждающего змеевика в проверенных полевых файлах не установлен. G36 предоставляет внутренний модельный расход, RBC-Nesbitt — канал plant. Возможность установки прибора описана без оценки стоимости и эффективности.
- Cooling Mode — команда последовательности. Она может экспортироваться BAS при подтверждённом словаре точек. Физическое состояние охлаждения остаётся `UNKNOWN`.
- Метод локализации не допущен к реализации. Новых экспериментальных расчётов, подбора порога или обработки fault-значений для квалификации не было. Продуктовые регрессии использовали только ранее принятое правило.

## Продуктовая часть

- G36-1wk API явно возвращает `paired_causal_gate=STOP`, `unpaired_descriptive_gate=PASS` и `runs_per_scenario=1`. Историческое `SOURCE_METADATA_QA.score_computed=false` относится к отдельной метаданной проверке G5.3.
- Investigator показывает один симуляционный прогон на сценарий, число минутных отсчётов и отдельно четыре начала подтверждения в сценарии клапана. Они отмечают эпизоды симптома внутри одного прогона. Для двух крайних записей в EXTRA_SIMULATED показан `SOURCE_ORACLE_EXCEPTION`. BASIC возвращает пустое значение oracle и прежний результат.
- Общий предикат, CLI G5.4 и сервис G36-5wk совпали побайтово с принятой основой. Сравнение 5wk совпало с G5.3. Проверенные 1wk HTTP-ответы после удаления новых полей совпали с G5.4.

## Проверки и отрицательные контроли

- 310 pytest passed, 73 предупреждения. Негативные тесты проверяют запрет вызова oracle reader из BASIC, изменение ground truth, неизвестный/недостоверный mode, дополнительный канал с общим источником, отсутствующий кандидатный канал, неверную единицу, а также обе крайние записи и равенство BASIC/EXTRA по исходным диагностическим полям. Контроли кандидатов проверяют границу текущего BASIC, поскольку новых оценщиков нет.
- OpenAPI, TypeScript strict build, воспроизводимость сгенерированных типов и восемь фикстур — PASS. Vite выдал предупреждение о размере сборки.
- HTTP и Playwright — PASS. Chromium проверен на 1440×900 и 390×844 для 1wk и 5wk.
- Docker backend smoke — PASS. Полный Compose — NOT_RUN.
- Первая попытка pytest обнаружила, что временная SQLite унаследовала режим read-only. Разрешение записи исправлено только на временной тестовой копии, затем выполнен полный повтор. Оригинальные CSV, Parquet, SQLite и сохранённая основа совпали по SHA до и после работы.

Наблюдаемость, несовместимость и недостающие источники разделены в матрицах. Нерешённые вопросы перечислены в `OPEN_RISKS_G5_5.md`.
