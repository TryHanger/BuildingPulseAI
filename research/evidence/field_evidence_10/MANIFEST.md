# Package contents

- `field-evidence-10.patch` updates the three existing route and navigation files.
- `overlay/` adds the implementation, tests, tools and research OpenAPI contract.
- `frozen-data/` contains the frozen runtime JSON and its SHA-256. The JSON includes original publisher file IDs and hashes, Stage09 trace hashes and source manifest identity.
- `screenshots/` contains full-page Chromium captures of AHU1, AHU23 intervention and matched control, AHU24 with open provenance, and AHU8 with missing observations.
- `evidence/` records baseline verification, oracle and test output, HTTP parity, complete before/after OpenAPI, versions, Docker availability, source protection and patch application.
- `FIELD_EVIDENCE_10_GATE_RESULT.md` records the release decision and scientific scope.
- `README_REPRODUCE.md` gives application and audit commands.
- `SHA256SUMS` pins every payload in this delivery.
