# Архивный виртуальный SAT · RESEARCH_ONLY

- Источник — официальная симуляция LBNL SD-AHU, 2018, без установленного смещения UTC. Входное время — источник-локальный календарь с минутным шагом. Температура — °F, номинальные сдвиги по условным ярлыкам — °C.
- Режим — PRODUCT_BASIC с командами и сохранённым `lbnl-fan-hold@1.0.0` RUNNING 300 с. Входы получены из BRICK и пересечены с реестром допустимых BASIC-каналов и известными единицами. Календарь формируется только из времени данной минуты. SA_TEMP исключён из собственных признаков. Команды могут отражать реакцию регулятора.
- В реестре восемь нативных LightGBM, seed 42, без отдельного скалера входов. Для каждой цели сохранены центр и масштаб абсолютного остатка по healthy calibration. Для SAT z = (|actual − predicted| − center) / scale, день — среднее z по допустимым минутам. Тип тревоги MODEL_ANOMALY при строгом превышении 3. Применение ограничено архивным сравнением.
- Train и calibration используют только здоровый сценарий и заканчиваются до 2018-10-20. Test — до 2019-01-01 (исключая границу). В UI доступны первые семь календарных дней test в двух фиксированных рядах. Целевые значения этих окон используются для расчёта остатка после прогноза.
- `registry/MODEL_ARTIFACT_MANIFEST.json` закрепляет SHA архива, обучающего CSV, TTL, упорядоченной схемы, протоколов, файлов моделей и небольших архивных окон. Runtime принимает реестр только из локального каталога с заранее заданным SHA манифеста. SHA подтверждает соответствие доверенному значению, которое устанавливает оператор. Проверяются структура, роли BASIC, нормировка и нативный порядок входов SAT. Произвольные файлы или параметры обучения через API отсутствуют.
- Ошибки целостности возвращают 503. Отсутствие обязательного канала, вырожденный масштаб и дни без допустимого режима возвращают NOT_EVALUABLE. Суточное покрытие — доля оценённых минут от 1 440. Сравнение с исправным прогоном относится к этому же симулятору.
- Все четыре условных ярлыка `coi_bias` → `sa_bias` имеют статус UNVERIFIED_PUBLISHER_ALIAS. FULL по статье содержит модельные величины. Дневные AUC и тревоги в этом исследовании не устанавливают точность на реальном здании или физическую причину.
