# PROTOCOL_G5_1_v1

## Decision rules frozen before the CSIRO eligibility sweep

Target: `CONTROLLED_BMS_INTERVENTION_PRESENT` within publisher-documented interval vs `UNKNOWN_UNANNOTATED` outside it. Injections are controlled proxies on operational equipment. Physical travel, independent temperature reference, and actual mechanism have separate provenance. Unannotated time supplies coverage context only. A verified reference requires a separate run log and verification of operating regime.

- Minimum data qualification for one family: ≥35 independent candidate blocks, with ≥10 train, ≥5 calibration and ≥20 retrospective test blocks after exclusions. A block is at least an AHU/controller campaign-day with no other retained positive on that day. Connected overlap/adjacency and cross-midnight activity merge blocks. Shared building days also stay in one split. This is a minimum for descriptive evaluation. Even 20 independent perfect detections leave a one-sided 95% miss-rate upper bound of about 14%; dependence widens uncertainty. No established improvement claim.
- Publisher join semantics: same AHU and `start <= tick < end` in the source-local clock. Never round an event onset into a telemetry row or join nearest event. A first tick within one measured nominal cadence can support interval coverage. It does not establish physical onset or publisher-clock accuracy. Invalid intervals, duplicate label rows, same-AHU overlap and documented site-wide simultaneous treatment are excluded. For conservatism, any coincident or <30 min adjacent intervention on either AHU blocks isolated treatment unless independently cleared. Boundaries touching at exactly 30 min meet the washout. Repeated same-day events remain grouped even if separated.
- Require 30 min valid pre-context, event coverage and 30 min post-context. Complete nominal grid support with boundary tolerance of one cadence, no steps over one cadence, and no silent imputation. Boundary/censoring, input missingness and gaps are separate findings. Use measured modal positive cadence per AHU and exact timestamps; no inferred UTC offset. Within eligible windows require a logged regime, objective non-oracle response, known point provenance and excitation (nonconstant valid control demand with a preregistered engineering excursion; until native units/pre-override identity are verified, excitation is UNKNOWN). Candidate families and bounds derive from README and raw fault taxonomy, without model scores.
- Split design if qualified: exclude previously reviewed episodes and entire touched AHU/building days as exploratory. Hold AHU/campaign clusters together and then cut ordered, non-overlapping complete building days into train → calibration → retrospective test. Both AHUs in the same building are dependent. Exact partition dates and IDs require qualified blocks and an exposure ledger, so no executable split is assigned when the gate fails. No claim of blind evaluation without sealed custody of new data. No minute-level shuffle. No overlap of context or washout across split boundaries.
- Output qualification metrics: label coverage and eligibility counts with total scheduled time and telemetry denominators. If later approved, event recall is qualified intervention blocks with a new alert / all qualified blocks; report misses, abstentions and exclusions. Precision relative to documented interventions requires a qualified reference population and disclosed unknown/unassigned alerts. Unknown alerts never become false positives or negatives. On verified normal only, report alert episodes per assessed hour and coverage, no production FAR. Delay requires an independently qualified activation clock and observed onset; otherwise null. Sustained alerts from before the event are pre-active, not detections of new onset.
- Input governance: candidate physical observations must be distinct, correctly bound and separate from the injection path. No experiment ID, exact event time, time-since-onset, scheduled magnitude, label, proxy override bit, injected command or injected sensor as an oracle. Do not treat a BAS command as achieved position. No training, detection scores, thresholds fitted to data, or comparison with the separate G5 LBNL nominal pilot.
