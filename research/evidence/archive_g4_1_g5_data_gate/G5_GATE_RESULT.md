# BuildingPulse G4.1 / G5 · результат gate

7 ноября 2026 · Asia/Qyzylorda

| Gate | Решение |
|---|---|
| G4.1 closeout | **PASS** для принятого продуктового workflow. |
| G5 source qualification | **PASS** для инвентаря, ролей, номинального источника и протокола. |
| G5 fault metrics | **STOP_G5_FAULT_METRICS**. Нет независимой квалифицированной размеченной fault кампании для выбранной задачи. |
| G5 coding | **TRAINING_NOT_AUTHORIZED**. `GO_DESCRIPTIVE` относится к постановке задачи на номинальном симуляционном годе. |

G4.1 отделяет четыре величины: оценённые отсчёты, нарушающие отсчёты без подтверждения, подтверждённые эпизоды и неоценённые отсчёты. В примере из 10 нарушающих наблюдений нет подтверждённых эпизодов. 11-е наблюдение выдерживает 600 секунд, подтверждая один эпизод. График называется «Температуры смешения (OA / RA / MA)». Пояснения по механизму, lineage и SHA перенесены в раскрытия. Топ-бар различает синтетический серверный источник и исторический UI mock. Read-only API rc.6 сохраняет прежние статусы и добавляет счётчик к JSON/HTML отчёту. Порог, исходный G3 индекс и SQLite не пересчитывались в runtime.

Сверены 21 CSV официального ZIP LBNL, 15 уникальных payload и 15 локальных префиксов. Имена `coi_bias/sa_bias` остаются UNKNOWN. Два семейства с повторёнными байтами исключены из severity. CSIRO подтверждён по Git LFS для двух телеметрий и журнала вмешательств. Сами байты подтверждают источник, а независимые ход клапана, эталон SAT и выбранная физическая метка требуют отдельной квалификации.

Постановка A фиксирует nominal residual измеренного SAT для `AHU_annual.csv`, BASIC и заранее заданную абляцию команды. Три календарных интервала непересекающиеся, но происходят из одной симуляционной кампании. Holdout ретроспективный. Независимых fault episodes и blind normal кампаний нет. Предметная закупка для B — синхронные инструментированные испытания AHU1 NIST IBAL. Доступные CD04 выгрузки проверяют привязку каналов при зарядке аккумулятора, без нужных fault labels.

## Проверки

| Проверка | Результат |
|---|---|
| Регрессия backend, контракт, исследования | 291 pytest PASS. |
| Frontend и OpenAPI | Strict TypeScript и Vite PASS. Перегенерация OpenAPI типов побайтовая. 8 исторических fixtures и 5 фактических HTTP ответов проверены по типам. |
| HTTP и Chromium | G0–G3 и G4.1 PASS. Проверены 1440×900, 1280×800, 1024×768, 390×844, точный клик по времени, gap, 10/11 наблюдений и отдельный серверный источник без MAT. Снимки 1440/390 визуально просмотрены. |

Новая обучаемая модель, fault F1/AUC, полевой FAR, recall и delay не рассчитаны. Производственный статус приложения не пересматривался.
