# G5.7 · Реестр решений и корней свидетельств

| Решение | Статус | Основание |
|---|---|---|
| Аутентичность и геометрия модели | PASS_RESTRICTED | Шесть закреплённых SHA, заголовки 47/53 в K, два одинаковых рисунка издателя, разные узлы в родственном коде и сверенный nominal. Прямой crosswalk этого релиза остаётся неустановленным. |
| Буквальный алиас SAT | Отклонён для проверенных рядов | Точные совпадения только на подмножестве. На новом вычислении не использовалась другая единица или временной сдвиг. Смещение колонки относительно исходного экспорта отсечено SHA, а не корреляцией. |
| Дополнительное описание участка | SECTION_CONTEXT_SIM_ONLY | Предварительный критерий выполнен по обоим знакам. Пространственная ветка с пересечением SAT SP отсутствует. Изменения между сечениями обычно малы, включая номинал. |
| Изоляция причины, полевая оценка | AMBIGUOUS / FIELD_NOT_QUALIFIED | Общий симуляционный контур, неподтверждённое физическое состояние охлаждения, нет отдельной полевой кампании. |
| Парное сравнение 1wk | STOP | Сохранён прежний gate G5.3. |
| Включение coil-out в продуктовый расчёт | NOT_AUTHORIZED | Только описание происхождения в Sensor Lab. |
| RBC #7 | HYDRONIC_SCOPE_UNVERIFIED | Нет подтверждённого соответствия опубликованному plant-тегу и нет привязки к ветви AHU2. |

## Корни свидетельств

| Переменная | Роль в эксперименте | Зависимости |
|---|---|---|
| SAT, #47 | Frozen BASIC, температура после вентилятора согласно модели участка | Входит в SAT−SP и в SAT−coil-out. Участвует в обратной связи регулятора. |
| MAT, #51 | Frozen BASIC, модельное смешение | MAT−coil-out использует ту же MAT и охватывает нагреватель и охладитель. |
| Coil-out, #53 | Дополнительное модельное сечение за охладителем | Тот же симуляционный контур, общие граничные условия, динамика воздуха и управления. Коэффициент зависимости от полного BASIC не оценивался. |
| SAT SP и две команды | Задание и управляющие входы существующего BASIC | Привязаны к тому же контуру. SP используется только как общий геометрический ориентир. |
| Статус вентилятора, OAT/OWB | Симуляционный контекст | Fan status даёт страты, weather используется по прежним правилам. Физический охлаждающий режим UNKNOWN. |
| True Valve Position, CHW flow, COIL_Q, publisher label | За границей вычисления | Маска, выдержка и разности их не читают как признаки. |
