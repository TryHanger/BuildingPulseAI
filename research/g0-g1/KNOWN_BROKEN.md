# Известные проблемы и ограничения G0–G1

- **Историческое повреждение семи ID событий SQLite.** В первом G0-аудите тест `/api/ml/detect` перезаписал семь событий сценария `sc_1c55da332333` в рабочей БД. Интервал изменения относится к первому тестовому прогону G0, точное время и исходный список ID не сохранились. Временные данные набора `ds_cf9a19fe80af`, созданные тем аудитом, были удалены. Побайтовой копии БД до перезаписи нет. Исторические event IDs **не восстановлены**. Текущий handoff сохраняет полученный снимок SQLite и сравнивает его SHA с исходником.
- **Legacy rules и качество.** `DiagnosticsService.run_baseline_rules` использует `vs-sa-temp-v2`. Старые временные фильтры могут расходиться с длиной полного прогноза. Исторический DQ работает по обработанному ряду и не восстанавливает перестановки, скрытые в прежних импортированных Parquet. Новый путь v1 использует сверенный источник CSV и его замороженную годовую производную для оконных запросов.
- **Историческая семантика.** Существующие ML-ветки содержат эвристики для температурных единиц. В v1 давление и его уставка имеют статус `UNVERIFIED_UNIT`, отображаются сырыми и с предупреждением. Проверка физической размерности и испытания pressure/flow остаются `BLOCKED_BY_DATA`. Исторические поверхности LEGACY_ANALYSIS сохраняют прежние метаданные. Сатурация команды совместима со здоровой симуляцией и не определяет поломку клапана.
- **Импорт после аварийного завершения процесса.** При обычном исключении БД откатывается и опубликованные в этой попытке файлы удаляются. Прерывание процесса между публикацией файлов и коммитом может оставить недоступные через API файлы. Повтор с тем же SHA может использовать совпадающий raw; старый несвязанный Parquet требует отдельной уборки по манифесту.
- **Источники и пары.** Alias `coi_bias` → `sa_bias` не подтверждён. Группы `coi_leakage` и `oa_bias` остаются BLOCKED для severity. Проверка сопоставимости пар и привязка LBNL к UTC открыты.
- **Среда и зависимости.** Git metadata отсутствуют в переданном снимке. Исходный npm audit сообщил три уязвимых пакета, включая high Vite. После обновления lock-файла повторный аудит сообщил 0 уязвимостей. Полные идентификаторы сохранены в handoff rc.2. Vite предупреждает о размере существующего бандла. scikit-learn предупреждает о версии сериализованных legacy-моделей 1.8.0 при запуске с 1.9.1. Регрессионные тесты прошли, а v1 эти модели не загружает.

- **Годовой индекс.** Годовой индекс доступен с замороженным Parquet. Предыдущий DATA_ROOT без него использует более медленный последовательный проход по сверенным блокам CSV. Производительность этого режима не входит в замеры индексированных окон. Остальные проверенные срезы читаются из CSV.
- **G2.** Валидация физического режима economizer и флага разрешения охлаждения остаётся `BLOCKED_BY_DATA`. Кандидат fan transition hold ожидает отдельного согласования, полный G2 остаётся `NOT_TESTED`.
