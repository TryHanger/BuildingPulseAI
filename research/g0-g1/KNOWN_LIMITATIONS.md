# Ограничения G0/G1

| Ограничение | Последствие для G1 |
|---|---|
| 21 имя, 15 уникальных CSV; две группы одинаковых данных | Запрещено считать разные имена отдельными классами/интенсивностями |
| `coi_bias` не идентифицирован как `sa_bias` | Запрещены verified SAT injection, парное демо и переименование |
| Симулированные измерения и weather TMY, годовые воздействия | Нет натурного обобщения и latency без независимо указанного onset |
| Naive Datetime, модельный режим и переходы ещё не приняты | Legacy timestamps сохраняем как есть. UTC replay по v1 выдаёт `UNAVAILABLE` |
| PDF указывает `>60°F`, `<33.8°F`, промежуточный economizer и «greater than 100%» | Для точных границ и насыщения требуется decision table G2. Нельзя подменять открытие командой или generic G36 |
| Fan-on в нерабочее время может означать cycling; расписание не заменяет proof | Не считать fan-on достаточным условием активности SAT regulation |
| Давление, расходы и feedback требуют дополнительной семантической QA | Не использовать для физического вывода по единичному образцу |
| BASIC содержит команду, но не actual feedback; поток/влажность отсутствуют | Mismatch и thermal balance `NOT_EVALUABLE`. EXTRA даёт только симулированный feedback |
| Legacy import может записать строку `NaT`, так как преобразует к строкам до `dropna` | Контракт G1 описывает целевую семантику, не исправляет существующий импорт |
| Наблюдения с общей погодой или одним SAT не независимы | Не суммировать свидетельства как независимые, не выпускать posterior или изолированную причину |
| OpenAPI является draft; JSON Schema + семантический валидатор проверены на fixtures | G1 не объявляет рабочим v1 endpoint, реальный режим, событие или проверенную причину |
| Архивный checkout без Git | Commit, diff и worktree не верифицированы. Использованы SHA-256 файлов |
| Docker daemon доступен; config валиден; известен дефект Dockerfile | Docker runtime и Vite full build остаются непроверенными, dev fallback проверен backend тестами и TS frontend |
