## 2. Реализованная UX-карта 8 представлений

1. **`/incidents` — Лента инцидентов:**
   - Фильтры по 4 состояниям обнаружения (`DETECTED`, `NOT_EVALUABLE`, `AMBIGUOUS`, `CONFLICTED`) и по установкам.
   - Отсутствие выдуманных процентов вероятности и ложных заявлений «100% healthy».
   - Карточки с правилом, интервалом, описанием симптома, ограничениями наблюдаемости и рекомендованными действиями из белого списка.
   - Кнопка «Перейти на таймлайн» с автоматической установкой курсора и переходом в AHU Investigator.
2. **`/assets/:id` — AHU Investigator (Главное рабочее место инженера):**
   - **Верхняя панель:** Плашки происхождения (`Simulation (LBNL)` / `Field (CSIRO)` / `Demo Fixture`), единый `ReplayClockBar` (Play/Pause, Seek, Scrub, Скорость x1/x5/x20, UTC и местное время, статус подтверждения работы вентилятора, предупреждения о пропусках).
   - **Левое меню:** Иерархия оборудования (LBNL SD-AHU 01, CSIRO AHU-10, CSIRO AHU-09, Demo Unit).
   - **Центральная мнемосхема:** Высококонтрастная 2D SVG-схема AHU с привязкой каналов строго к `canonical_signal_id`, анимацией вращения вентилятора только при подтвержденном `fan_on`, явной индикацией отсутствия физических датчиков (например, `[Не установлен в BASIC]`), без выдумывания расхода воздуха `SA_CFM` при отсутствии расходомера.
   - **Правая карточка:** `EvidenceInspectorCard` с 4 независимыми осями статусов (`Data State`, `Cause State`, `Model Scope`, `Ground Truth`), разбором гипотез, неисполняемыми проверками и интерактивным графом связей.
   - **Нижняя область:** 3 синхронных графика Apache ECharts со связанным курсором, разрывом ночных пауз (`connectNulls: false`) и сырым зумом без искусственного сглаживания.
3. **`/incidents/:id` — Детальный просмотр инцидента и свидетельств:**
   - Полный drill-down по гипотезам, поддерживающим/опровергающим/отсутствующим свидетельствам, причинам неисполнимости проверок и графу причинности.
4. **`/research` — Научный хаб:**
   - Матрица методов, гипотезы H1–H4, результаты переноса на реальное здание CSIRO AHU-09/10, честное признание компромиссов без скрытого подгона под тест.
5. **Контекстная вкладка: `Sensor Lab`:**
   - Переключение профилей (`BASIC`, `BASIC_PLUS_VALVE`, `BASIC_PLUS_DAMPER`, `FULL`).
   - Матрица доступности каналов (записан в источнике / семантика верифицирована / статус в профиле).
   - Кнопка отправки запроса на пересчет на сервере (фронтенд не выполняет физический инференс).
6. **Контекстная вкладка: `Сравнение Норма / Авария`:**
   - Наложение кривых допускается только для подтвержденных пар симулятора (`pair_id = pair-lbnl-summer-25`) с общим погодным файлом.
   - Для невалидных пар (например, зима vs весна CSIRO) наложение жестко заблокировано с понятным физическим обоснованием причины.
7. **Контекстная вкладка: `Качество и Режимы`:**
   - Панель монотонности времени, интервалов пропусков (Data Gaps), замирания (Stuck Signal) и журнал режимных переходов LBNL State Machine.
8. **Контекстная вкладка: `Инженерный Аудит и Отчет`:**
   - Отображение хэшей исходных данных, статуса Ground Truth (`NO_GROUND_TRUTH`), версий и кнопки экспорта с оговоркой доступности реального backend API.
